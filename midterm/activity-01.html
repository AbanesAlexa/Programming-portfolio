MIDTERM LAB TASK 01

Using 2 Dimensional Arrays

This activity focuses on using a two-dimensional array to store and process numbers in a 3 × 3 matrix. It helped me understand how rows and columns work when handling multiple values in Java.

What I Did

  • Stored 9 integers in a 3 × 3 matrix.
  • Calculated the sum of each row.
  • Calculated the sum of each column.
  • Calculated the sums of both diagonals.
  • Added an option to repeat the program.

What I Learned

Through this activity, I learned how to organize numbers using rows and columns in a two-dimensional array. I also practiced using nested for loops to access and calculate the values. At first, I found the process confusing, but doing the activity helped me understand how arrays make handling multiple values easier.
