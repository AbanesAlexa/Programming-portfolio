Using 2 Dimensional Arrays.

This activity focuses on using a 2-dimensional array in Java to store and process nine integer values in a 3×3 matrix. The program calculates the sum of each row, each column, and both diagonals.

WHAT I LEARNED

Activity Overview

I learned how to organize numbers into rows and columns using a 2-dimensional array. I also practiced using nested loops to access and process each element.

The program calculates row sums, column sums, and diagonal sums, and allows the user to repeat the process.
