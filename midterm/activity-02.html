Using 3 Dimensional Arrays.

This activity focuses on creating a Student Grade Management System using a 3-dimensional array in Java. It stores the grades of students from two sections in Java, Database, and Networking.

WHAT I LEARNED

Activity Overview

I learned how a 3-dimensional array organizes information into sections, students, and subjects.

The program displays student grades, calculates each student's average, and determines the overall average of each section.

I also practiced using nested loops to access the correct values. At first, understanding how three indexes work together was challenging, but completing the activity helped me become more familiar with multidimensional arrays.
