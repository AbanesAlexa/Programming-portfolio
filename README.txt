ALEXA'S PROGRAMMING PORTFOLIO - STARTER FILES

WHAT IS INCLUDED
- index.html: the main airline-ticket portfolio homepage
- style.css: the design and layout
- midterm/: your midterm folder and sample activity pages
- final-term/: your final-term folder and sample activity pages

HOW TO USE
1. Upload all files and folders to the root of your GitHub repository.
2. Keep the folder names exactly as they are: midterm and final-term.
3. Open index.html through GitHub Pages after enabling Pages.
4. Replace the sample activity names and descriptions with your real task names.
5. Upload your Java source files, screenshots, PDFs, or other required submissions into the correct term folder.
6. Link each uploaded file from the relevant activity page.
